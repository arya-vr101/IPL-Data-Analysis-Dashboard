# IPL Data Analysis Dashboard (2008–2017)

This project presents an **interactive IPL Data Analysis Dashboard** built using **Microsoft Excel**.  
The dashboard analyzes **Indian Premier League (IPL) match data from 2008 to 2017** to identify trends, team performance, and player statistics.

---


## Project Objective

The objective of this project is to analyze IPL match data and provide insights such as:

- Total matches played by season
- Team performance and total wins
- Toss win distribution
- Top run scorers
- Man of the Match winners
- Venue-wise match distribution
- Season match trends

---

## Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Slicers & Timeline Filters
- Dashboard Design

---

## Dataset Used

The project uses two datasets:

### matches.csv
Contains match-level information:
- Season
- Venue
- Winning team
- Toss winner
- Player of the match

### deliveries.csv
Contains ball-by-ball match data:
- Match ID
- Batsman
- Runs scored
- Ball delivery details

These datasets were used to create pivot tables and visualizations for the dashboard.

---

## Dashboard Insights

### Matches Held by Season
Shows how the number of IPL matches changed from **2008 to 2017**.

### Total Wins by Team
Displays the number of matches won by each team.

### Toss Wins Distribution
Illustrates which teams won the most tosses.

### Top 10 Run Scorers
Shows the batsmen with the highest total runs.

### Man of the Match Winners
Highlights players who received the most **Player of the Match awards**.

### Matches by Venue
Displays which stadiums hosted the most matches.

### Season Match Trend
Shows the trend of matches across different IPL seasons.
